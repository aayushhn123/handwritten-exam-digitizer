Pipeline

Waiting for a file
  1. UploadYour file is sent to the local server
  2. Split into pagesEach PDF page becomes a high-resolution image
  3. Enhance the imageRemove rules, shadows and colour; straighten
  4. Read the handwritingTesseract OCR turns pixels into characters
  5. Find key detailsStudent ID, question no., marks, page no.
  6. Build the recordText + details + confidence, per page

How the project evolved

    


    

      
!

      

        What we learnt about accuracy
        
Week 5: the original cleaning step (adaptive thresholding + deskewing) made OCR worse on phone photos of ruled notebook pages, because it thickens the ruled lines until they merge with the letters.

        
Week 7: the new enhancement works with the photo instead: it reads only the red colour channel (so pink and red rules disappear), evens out lighting, and erases the remaining rules without hard black-and-white conversion. Average character error rate went from 42.6% to 18.9% (neat handwriting 39.7% → 3.7%, cursive 45.5% → 34.1%) at about one second per page.

        
Also tested and rejected: Microsoft TrOCR (similar accuracy, about 3-5 minutes per page on CPU), reading line by line (worse), and Tesseract's larger “best” model (no gain, twice as slow).
